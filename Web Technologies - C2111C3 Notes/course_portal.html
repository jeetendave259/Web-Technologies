Unit 1: Introduction to WWW

Total Hours: 04

Internet vs. WWW

The Internet is a massive network of networks, a networking infrastructure. It connects millions of computers together globally. The World Wide Web (WWW) is a way of accessing information over the medium of the Internet. It is an information-sharing model that is built on top of the Internet.

HTTP Protocol: Request and Response

The Hypertext Transfer Protocol (HTTP) operates as a request-response protocol between a client and server. A web browser (client) submits an HTTP request message to the server. The server, which provides resources such as HTML files and other content, returns a response message to the client containing the requested content and status information.

Web Browser and Web Servers

  • Web Browser: A software application for accessing information on the WWW (e.g., Chrome, Firefox, Edge). It renders HTML, CSS, and executes JavaScript.
  • Web Server: Hardware or software that responds to client requests over the WWW (e.g., Apache, Nginx, Microsoft IIS).

Features of Web 2.0

Web 2.0 highlights user-generated content, usability, and interoperability. Key features include social media networking, AJAX-driven dynamic content, blogging, and rich internet applications (RIAs) that allow users to interact and collaborate in a social media dialogue.

Setting up Unix/Linux Web Servers & Dynamic IP

Deploying web applications often requires configuring Apache or Nginx on Linux environments. Dynamic IP addresses are temporarily assigned to devices by a DHCP server, which requires dynamic DNS (DDNS) setups if a server must be accessed publicly via a consistent hostname.

Concepts of Effective Web Design and Issues

Effective design encompasses visual hierarchy, responsive layouts, accessibility, and fast load times. Common design issues include cross-browser compatibility, handling varied screen resolutions, and ensuring intuitive navigation.

Unit 2: HTML

Total Hours: 07

Basics of HTML, Formatting, Fonts, Colors, Hyperlinks

HTML (HyperText Markup Language) is the standard markup language for creating web pages. Elements are represented by tags. Standard formatting includes <b>, <i>, and <u>. Hyperlinks are created using the anchor tag <a href="url">, and colors can be applied via inline CSS or deprecated HTML attributes.

Lists, Tables, Images, Forms

  • Lists: Ordered (<ol>) and Unordered (<ul>) lists containing list items (<li>).
  • Tables: Structured data using <table>, <tr> (rows), and <td> (data cells).
  • Images: Embedded using the <img src="path" alt="text"> tag.
  • Forms: Collect user input using <form>, containing various <input> fields, textareas, and buttons.

HTML5 New Elements & Input Types

HTML5 introduced semantic tags like <header>, <footer>, <article>, and <section>. It also introduced new input types for forms, such as email, date, range, and color, which provide built-in client-side validation.

HTML5: Drag/Drop, Video, Audio

HTML5 allows native multimedia embedding without third-party plugins using the <audio> and <video> tags. The Drag and Drop API allows users to click and drag elements to a different location or drop target on the webpage.

XHTML: Meta Tags

XHTML is a stricter, XML-based version of HTML requiring properly closed tags and lowercase attributes. <meta> tags provide metadata about the HTML document, utilized by browsers (how to display content) and search engines (keywords, author, description).

Unit 3: CSS

Total Hours: 04

Need for CSS, Introduction, Syntax and Structure

Cascading Style Sheets (CSS) separates content (HTML) from presentation (styling). A CSS rule consists of a selector and a declaration block: selector { property: value; }. This allows for global style changes across multiple web pages from a single `.css` file.

Background Images, Colors and Properties

CSS controls backgrounds via properties like background-color, background-image, background-repeat, and background-size, allowing for complex visual layering.

Manipulation of Texts: Font, Border and Boxes

The CSS Box Model is fundamental, dictating that every element is a box composed of margins, borders, padding, and the actual content. Text manipulation involves properties like font-family, font-size, text-align, and line-height.

CSS Positioning CSS2, Overview and Features of CSS3

  • CSS2 Positioning: Includes static, relative, absolute, and fixed positioning.
  • CSS3 Features: Introduced advanced styling capabilities like media queries for responsive design, flexbox, grid, transitions, animations, rounded corners (border-radius), and box shadows.

Unit 4: Introduction to JavaScript and JQuery

Total Hours: 15

Client-side Scripting: Variables, Conditions, Loops, Functions

JavaScript provides logic and interactivity to web pages. Variables store data (let, const, var). Control flow is managed via if/else statements and loops (for, while). Functions encapsulate reusable code blocks.

Advanced JavaScript: Objects & DOM

JavaScript is an object-oriented language. The Document Object Model (DOM) is a programming interface for HTML, representing the page so that programs can change the document structure, style, and content dynamically.

Forms, Validations, Events, and Buttons

JavaScript intercepts form submissions to perform client-side validation (ensuring fields aren't empty, passwords meet length criteria, etc.) before sending data to the server. This is achieved by attaching event listeners (like onclick or onsubmit) to buttons and form elements.

DHTML & AJAX

  • DHTML: Dynamic HTML refers to the combination of HTML, CSS, and JavaScript to create interactive and animated web sites.
  • AJAX: Asynchronous JavaScript and XML allows web pages to be updated asynchronously by exchanging small amounts of data with the server behind the scenes, eliminating the need to reload the entire page.

JQuery: Introduction

jQuery is a fast, small, and feature-rich JavaScript library. It makes things like HTML document traversal and manipulation, event handling, and AJAX much simpler with an easy-to-use API that works across a multitude of browsers.

Unit 5: XML

Total Hours: 08

Introduction to XML & Key Components

eXtensible Markup Language (XML) is designed to store and transport data, focusing on what data is rather than how it looks. Key components include custom tags, elements, attributes, and a strictly hierarchical tree structure.

DTD and Schemas

A Document Type Definition (DTD) defines the structure and the legal elements and attributes of an XML document. XML Schemas (XSD) are an XML-based alternative to DTDs, providing stronger typing and more precise control over the data structures.

Transforming XML using XSL and XSLT

eXtensible Stylesheet Language (XSL) is a styling language for XML. XSLT (XSL Transformations) is used to transform XML documents into other formats, such as transforming XML data into an XHTML document for display in a web browser.

Unit 6: PHP

Total Hours: 10

Introduction to Server-Side Scripting & PHP Syntax

PHP (Hypertext Preprocessor) is a widely-used open source general-purpose scripting language that is especially suited for web development and can be embedded into HTML. PHP scripts execute on the server, generating HTML which is then sent to the client. Scripts are enclosed in <?php ... ?> tags.

String Processing and Regular Expressions

PHP offers powerful string manipulation functions. Regular expressions (using PCRE functions like preg_match) allow for complex pattern matching, searching, and replacing within strings, which is vital for sanitizing and validating user input.

Web Development Frameworks

PHP frameworks (like Laravel, CodeIgniter, or Symfony) provide a basic structure for streamlining the development of web apps. They promote Rapid Application Development (RAD), enforce MVC (Model-View-Controller) architecture, and provide built-in security features to prevent SQL injection and cross-site scripting.
