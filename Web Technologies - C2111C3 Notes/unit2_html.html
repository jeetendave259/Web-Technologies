01HTML and the Basic Document

HTML means HyperText Markup Language. It is the standard markup language used to describe the structure and meaning of web content. HTML is not a programming language: its elements mark up text, links, images, forms, and other content so browsers can interpret and present them.

HyperText

Text containing links that connect one resource to another. Following links lets a reader navigate a web of documents.

Markup

Tags annotate content, for example marking a line as a heading, a paragraph, a link, or an image.

Browser

A browser reads HTML, builds a document tree, loads referenced resources, and renders the result for people to use.

A minimal, complete HTML5 document

Save the example as hello.html, then open it in any modern browser. The <!doctype html> declaration selects standards mode; head holds document information, while visible page content belongs in body.

<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My First Page</title>
</head>
<body>
    <h1>Hello, web!</h1>
    <p>This is my first HTML document.</p>
</body>
</html>
PartPurpose
<!doctype html>Declares an HTML document and asks the browser to use standards mode.
<html lang="en">Root element; its language helps assistive technology and other tools.
<head>Contains metadata, the page title, and links to resources such as stylesheets.
<meta charset="utf-8">Declares the character encoding so text is decoded consistently.
<meta name="viewport">Helps the layout use the device's actual viewport on mobile screens.
<title>Sets the browser-tab title and a useful name for bookmarks and search results.
<body>Contains the content rendered in the page.
History in brief: Tim Berners-Lee created the Web at CERN, with the first HTML specifications appearing in the early 1990s. HTML has evolved from simple linked documents into a standards-based language for accessible documents and interactive applications. Modern HTML is maintained as a living standard.

02HTML Elements, Nesting, and Attributes

An HTML element generally consists of an opening tag, content, and a closing tag. The element represents the whole structure; a tag is the markup at its boundary. Elements can be nested to express relationships, and the inner element must close before its parent.

<p>This paragraph contains <strong>important text</strong>.</p>

Some elements are void elements: they have no child content and do not use a closing tag. Common examples include <br>, <hr>, <img>, and <input>. Use lowercase tag and attribute names and quote attribute values for readable, consistent HTML.

Attributes add information to an element

Attributes appear in the opening tag, usually as a name and quoted value. Global attributes such as id, class, lang, and title can be used on many elements; others, such as href and src, apply to specific elements.

<a href="https://example.com/" title="Visit the example site">
    Example website
</a>

<img src="images/flower.jpg" alt="A yellow flower" width="320" height="220">

href

Provides the destination of a link.

src

Provides the address of an embedded resource, such as an image or media file.

alt

Gives a text alternative for an image. Describe its purpose, or use empty text for decorative imagery.

id and class

Identify an element or group of elements for navigation, CSS, and scripts.

Do not rely on browser error recovery: Browsers may display malformed HTML, but omitted end tags or incorrect nesting can produce unexpected document trees. Close elements correctly and validate your page while learning.

03Headings, Paragraphs, and Text Formatting

Use headings to communicate the outline of the content, not merely to make text look large. A page normally has one descriptive top-level heading followed by logically nested section headings. Use paragraphs for blocks of prose; browsers collapse repeated spaces and line breaks in ordinary HTML text.

<h1>A Guide to Gardens</h1>
<h2>Choosing a location</h2>
<p>Most herbs grow well in a bright, sheltered place.</p>
<h2>Preparing the soil</h2>
<p>Remove weeds and loosen the soil before planting.</p>
<hr>
<p>New section after a thematic break.</p>

04Styles, Fonts, and HTML Color Values

HTML provides structure and meaning; CSS is the recommended language for visual design. The presentation introduces the style attribute as a way to demonstrate CSS declarations directly on an element. Inline styles are useful for a tiny experiment, but for real pages prefer a stylesheet so design can be reused and maintained.

<p style="color: #075752; background-color: #e6f4f1;">
    This paragraph has a text color and a background color.
</p>
<p style="font-family: Georgia, serif; font-size: 1.25rem; text-align: center;">
    A larger, centered line of text.
</p>

05Hyperlinks and URLs

The anchor element <a> makes a hyperlink. Its href attribute identifies a destination. A destination can be an absolute URL, a relative path, an email address, or a fragment identifier linking to a section on the same page.

<!-- Absolute URL: includes scheme and domain -->
<a href="https://developer.mozilla.org/">MDN Web Docs</a>

<!-- Relative URL: another file in this folder -->
<a href="about.html">About this site</a>

<!-- Fragment URL: an element with this id on this page -->
<a href="#forms">Jump to the forms section</a>

<!-- Email link -->
<a href="mailto:student@example.edu">Email the student</a>

<!-- A new tab; use rel protection with target="_blank" -->
<a href="https://example.com/" target="_blank" rel="noopener noreferrer">
    Open example in a new tab
</a>

Absolute path

A full URL, such as https://example.com/guide.html, identifies a resource independently of the current page's directory.

Relative path

A path such as images/logo.png is resolved from the current document's location. Use ../ to move up one directory.

Link purpose

Write descriptive link text that makes sense out of context. Avoid vague labels such as “click here.”

Security and usability: Keep links as links and buttons as buttons. A button performs an action; a link navigates. If a link opens a new tab, make that behavior clear to the user.

06Lists and Tables

Choose the list type for the information

  • <ul> is an unordered list when item order is not important.
  • <ol> is an ordered list when sequence or ranking matters.
  • <dl> is a description list of terms and their descriptions.
<h3>Packing list</h3>
<ul>
    <li>Notebook</li>
    <li>Pen</li>
</ul>

<h3>How to submit</h3>
<ol>
    <li>Write the document.</li>
    <li>Save it as an HTML file.</li>
    <li>Open the file in a browser.</li>
</ol>

<dl>
    <dt>HTML</dt>
    <dd>Markup used to structure web content.</dd>
</dl>

Tables are for tabular data

Build a table from rows (<tr>), data cells (<td>), and header cells (<th>). Use a caption and meaningful row or column headers. Do not use tables to position page layouts.

<table>
    <caption>Weekly study plan</caption>
    <thead>
        <tr><th scope="col">Day</th><th scope="col">Topic</th></tr>
    </thead>
    <tbody>
        <tr><th scope="row">Monday</th><td>HTML structure</td></tr>
        <tr><th scope="row">Wednesday</th><td>Links and forms</td></tr>
    </tbody>
</table>

07Images and Alternative Text

The void element <img> embeds an image. Its src points to the image file, and its alt attribute provides a text alternative. The browser uses width and height to reserve the image's space and reduce layout shifts; CSS can control responsive display.

<img
    src="images/campus-garden.jpg"
    alt="Students tending a garden beside the campus greenhouse"
    width="800"
    height="520">

Use relative paths for files in your project, and keep filenames and directory structure accurate. Useful formats include JPEG for photographs, PNG for lossless images and transparency, SVG for scalable vector artwork, and WebP/AVIF for modern compressed images where supported. Animated GIF/APNG/WebP may be suitable for short animations.

Meaningful image

Describe the information or function the image adds. For a linked image, the alternative text should describe the link's destination or purpose.

Decorative image

Use alt="" when the image adds no information beyond nearby text, so assistive technology can skip it.

Do not write “image of” by default

Be concise and useful. Context may already make it clear that the content is an image.

An image can be a link

<a href="gallery.html">
    <img src="images/gallery-preview.jpg"
         alt="Open the campus photo gallery"
         width="240" height="160">
</a>
Try the example: Create an images folder next to your HTML file, place an image named campus-garden.jpg inside it, then open the page. If the file path is wrong, the alternative text remains a useful fallback.

08Forms and User Input

A form groups controls used to collect data. The action specifies where submitted data is sent, and method describes how it is sent. A server endpoint is required to process a real submission. Labels should be explicitly associated with controls using matching for and id values.

<form action="/register" method="post">
    <label for="student-name">Name</label>
    <input id="student-name" name="name" type="text" required>

    <label for="student-email">Email</label>
    <input id="student-email" name="email" type="email" required>

    <button type="submit">Register</button>
</form>

09Semantic HTML5 Page Structure

Semantic elements describe the role of a region, helping browsers, assistive technologies, developers, and search tools understand the page. Before HTML5, developers often used generic <div> elements for every region. A <div> is still useful when no more specific element fits, but use semantic markup where it communicates meaning.

<header> and <footer>

Introductory or closing content for a page or section.

<nav>

A major group of navigation links.

<main>

The unique, primary content of the document. Generally one visible main region per page.

<article> and <section>

A standalone composition and a thematic grouping, respectively; give sections a heading.

<aside>

Related or complementary content, such as a sidebar note.

<figure> and <figcaption>

Self-contained content such as an image or diagram with an optional caption.

<body>
    <header><h1>Student Journal</h1></header>
    <nav aria-label="Main navigation">
        <a href="#latest">Latest article</a>
    </nav>
    <main>
        <article id="latest">
            <h2>Learning semantic HTML</h2>
            <p>Elements give content a meaningful structure.</p>
        </article>
        <aside>Related reading: accessible web design.</aside>
    </main>
    <footer>Study notes, updated weekly.</footer>
</body>

10HTML5 Multimedia, Inputs, and Drag and Drop

Native audio and video

HTML media elements provide browser playback controls without requiring a legacy plug-in. Provide a source file in your project and fallback text for browsers that cannot play it. Multiple <source> elements allow the browser to choose a supported format.

<audio controls>
    <source src="media/intro.mp3" type="audio/mpeg">
    <source src="media/intro.ogg" type="audio/ogg">
    Your browser does not support embedded audio.
</audio>

<video controls width="640" poster="media/preview.jpg">
    <source src="media/lesson.mp4" type="video/mp4">
    Your browser does not support embedded video.
</video>

For a real video with spoken dialogue, include captions using a <track kind="captions"> file. Keep media files in the relative paths used by the markup, or replace those paths with the URLs of media you are permitted to use.

Newer form input types

HTML includes purpose-specific controls such as email, url, tel, date, time, number, range, and color. Browsers may provide appropriate controls and mobile keyboards. Built-in validation improves the user experience but does not replace server-side validation.

<label for="appointment">Appointment date</label>
<input id="appointment" name="appointment" type="date" required>

<label for="rating">Rating</label>
<input id="rating" name="rating" type="range" min="1" max="5" value="3">

Interactive drag-and-drop example

11Metadata, HTML, and XHTML

Metadata is information about the document, written inside <head>. It is not normally shown as page content. A useful title, character encoding, responsive viewport declaration, description, and icon are common examples.

<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <meta name="description" content="A beginner's guide to HTML.">
    <title>HTML Beginner's Guide</title>
</head>

HTML is the modern web markup language. XHTML is HTML expressed using XML's stricter syntax rules, such as properly nesting and closing elements and quoting attribute values. Do not add an XHTML doctype or serve a page as XML unless you are intentionally building an XML-serialized document; ordinary HTML pages should use the HTML5 doctype.

Good HTML habits

  • Start with the HTML5 doctype.
  • Declare the page language.
  • Use lowercase names and quoted values.
  • Nest elements correctly and use semantic elements.

Build for people

  • Use meaningful headings and link text.
  • Label form controls.
  • Provide useful image alternatives.
  • Check keyboard access and color contrast.

Test your document

  • Open the saved file in a browser.
  • Resize the viewport and try the controls.
  • Inspect the page source and browser developer tools.
  • Use an HTML validator to locate markup errors.

Unit 2 Recap

  1. HTML marks up content; a browser interprets the resulting document tree and renders it.
  2. Build complete documents with a doctype, root element, head metadata, and visible body content.
  3. Use elements, attributes, headings, paragraphs, and semantic formatting to communicate structure and meaning.
  4. Use anchors for navigation, lists for grouped items, tables for data, and images with appropriate alternative text.
  5. Forms collect user input; labels, names, input types, and validation attributes all matter.
  6. Semantic HTML5 elements, native media, and newer input types make pages more understandable and capable.
  7. Validate your markup and test the page with a browser, keyboard, and assistive-technology-aware practices.
