01Why CSS Is Needed

HTML describes the meaning and structure of content. CSS controls how that content is presented: its colors, typography, spacing, borders, and layout.

Separate content and design

Keep meaningful headings, paragraphs, lists, and forms in HTML. Put visual rules in CSS instead of repeating presentation attributes on every element.

Reuse one design

A single external stylesheet can style many pages. Updating one rule can keep a whole site consistent.

Adapt to screens

Media queries and flexible layouts let the same content work on phones, tablets, and desktop displays.

Reduce repeated work

Reusable selectors avoid copying the same style declarations into every HTML document. Browsers can also cache external stylesheets.

02CSS Syntax and Selectors

A CSS rule has a selector followed by a declaration block. Each declaration pairs a property with a value.

p.notice {
    color: #153c5b;                  /* property: value */
    background-color: #e8f2f8;
    border-left: 5px solid #2196f3;
    padding: 14px;
}
Selector: .notice
Properties: color, background-color, border-left, padding
Values: the settings after each colon
The matching paragraph

CSS applies the rule to an element whose class includes notice.

CSS Values, Units, and Custom Properties

A property only has an effect when it receives a value valid for that property. Values may be keywords such as auto, colors, numbers, lengths, percentages, or functions. A length usually needs a unit: 16px is a fixed CSS-pixel length, while relative units can adapt to text or the available space.

UnitRelative toCommon use
pxA CSS pixel, a reference unit rather than necessarily one physical screen pixel.Fine borders and small fixed details.
remThe root element's font size.Consistent, scalable typography and spacing.
emThe computed font size of the element (or, for font-size, its parent).Spacing that scales with text.
%A context determined by the property, often a parent dimension.Flexible widths and proportional sizing.
vw / vhOne percent of the viewport width or height.Sizing related to the visible browser area.

Custom properties, often called CSS variables, store reusable values. Names begin with two hyphens and are read with var(). Defining shared colors or spacing on :root makes them available throughout the document and easier to update consistently.

:root {
    --brand-color: #174f78;
    --space-medium: 1rem;
}

.notice {
    color: var(--brand-color);
    padding: var(--space-medium);
}

How the Cascade Chooses a Value

If several rules set the same property, the browser resolves the cascade by importance and origin, selector specificity, and then source order. The later rule wins only when the earlier comparisons are tied. Inline styles commonly outrank normal stylesheet rules but are not an unconditional highest priority.

p { color: #333; }          /* element selector */
.notice { color: #174f78; } /* class selector: more specific */
#warning { color: #a34b00; }/* ID selector: more specific still */

Inheritance and the Cascade

Some properties, especially text-related properties such as color and font-family, are inherited: a child can use the computed value of its parent when it has no value of its own. Many layout and box properties, such as margin, padding, and border, do not inherit by default. Inheritance is separate from specificity: the cascade first determines the value on an element, and inheritance can supply a value to a child when needed.

.article {
    color: #24313d;
    border: 1px solid #d7e0e5;
}

.article p {
    /* The paragraph inherits color, but not the border. */
    font-family: Georgia, serif;
}
Debugging tip: Browsers generally ignore an invalid declaration and continue parsing. Check spelling, values, braces, and semicolons when a style does not appear.

03Colors and Backgrounds

CSS accepts named colors, hexadecimal notation, RGB, and HSL. Alpha variants such as RGBA control the transparency of the color itself without making child text translucent.

Color can be applied to text with color and to an element's background with background-color. A background image or gradient is painted behind the content, so a fallback background color is helpful if an image cannot load. Choose text and background colors with sufficient contrast so content stays readable.

Box Model

From the inside outward, an element consists of content, padding, border, and margin. Padding is inside the border; margin separates the outside of one element from its neighbors.

With the default content-box sizing, a declared width applies only to the content; padding and border increase the rendered size. With border-box, the declared width includes content, padding, and border, which makes page layouts easier to calculate. Margins remain outside either box. In normal block flow, vertical margins of adjacent blocks can collapse into one margin rather than add together.

box-sizing: border-box includes padding and borders in the declared width. It is commonly applied globally.

CSS3 and Modern CSS Features

CSS is now developed as a collection of modules, such as Color, Selectors, Grid, and Media Queries. “CSS3” is still commonly used as a classroom label for newer features, but there is no single all-encompassing CSS3 or CSS4 release; individual modules evolve on their own timelines.

Choosing a Layout Method

Use normal document flow for most text and block content. Flexbox is useful for arranging items along one main direction, such as a row of navigation links. Grid is useful when a layout needs rows and columns together, such as a group of cards. These methods can be combined, and neither requires fixed pixel widths for every item.

Responsive layout: A media query applies rules only when a condition is true, such as a narrow viewport or a request to reduce motion. Choose breakpoints when the content needs them rather than targeting a particular phone model. Flexible tracks such as minmax() and auto-fit can adapt between breakpoints.
