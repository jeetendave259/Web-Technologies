01Introduction to Server-Side Scripting

A server-side script runs on a web server, not in the visitor's browser. The server can process a request, read or update data, apply application rules, and send back a response such as HTML or JSON. PHP (originally “Personal Home Page,” now commonly expanded as “PHP: Hypertext Preprocessor”) is an open-source scripting language widely used for web development. PHP code can be embedded in HTML and is executed by a PHP runtime on the server.

Browser / client

Sends an HTTP request, such as asking for a page or submitting a form. It receives the response and renders HTML, CSS, and JavaScript.

Web server + PHP

Routes the request to PHP, executes the script, and constructs a response. The PHP source is not sent to the browser.

Data store

A server-side application may read or write a database or files, subject to authorization and validation rules.

Request and response flow

  1. A browser requests a PHP route, for example http://localhost:8000/hello.php.
  2. The web server passes the request to the PHP interpreter.
  3. The script runs on the server and may combine data with an HTML template.
  4. The server sends the generated response to the browser; the browser displays the result.
Important: Opening a .php file by double-clicking it (a file:// URL) does not execute PHP. Use PHP's command-line interpreter or a web server configured with PHP. Never expose database passwords or private PHP source code in a public web directory.

First server-side script

Save this as hello.php. From the same directory, start PHP's local development server with php -S localhost:8000, then visit http://localhost:8000/hello.php. The command-line alternative is php hello.php, which prints the generated HTML in the terminal.

<?php
$name = 'Asha';
$hour = (int) date('G');
$greeting = $hour < 12 ? 'Good morning' : 'Hello';
?>
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>PHP greeting</title>
</head>
<body>
    <h1><?= htmlspecialchars($greeting . ', ' . $name, ENT_QUOTES, 'UTF-8') ?></h1>
    <p>This response was generated by PHP on the server.</p>
</body>
</html>

The opening tag <?php starts PHP code. The short echo tag <?= ... ?> outputs a value. The browser receives the resulting HTML—not the PHP statements that created it. htmlspecialchars() encodes text for safe insertion into HTML.

02Introduction and Basic Syntax of PHP

PHP statements are commonly written between <?php and ?> tags. A semicolon ends most statements. Variable names begin with $ and are case-sensitive; PHP keywords and function names are generally case-insensitive, but consistently use their conventional lowercase form. Use // or /* ... */ for comments.

Types, variables, arrays, and output

Save as basics.php and run php basics.php. It prints each line to the terminal.

<?php
declare(strict_types=1);

$student = 'Mira';
$unit = 6;
$passed = true;
$topics = ['PHP syntax', 'Strings', 'Frameworks'];
$marks = ['Mira' => 88, 'Dev' => 76];

echo "Student: $student\n";
echo 'Unit: ' . $unit . "\n";
echo 'Passed: ' . ($passed ? 'yes' : 'no') . "\n";

foreach ($topics as $index => $topic) {
    echo ($index + 1) . ". $topic\n";
}

foreach ($marks as $name => $score) {
    echo "$name scored $score\n";
}

Single-quoted strings are mostly literal; double-quoted strings can interpolate variables and interpret sequences such as \n. The dot (.) concatenates strings. Indexed arrays hold ordered values, while associative arrays map keys to values.

Conditions, loops, and functions

<?php
function resultLabel(int $marks): string
{
    if ($marks >= 40) {
        return 'Pass';
    }
    return 'Needs more practice';
}

$scores = [88, 35, 72];
foreach ($scores as $score) {
    echo "$score: " . resultLabel($score) . PHP_EOL;
}

A function groups reusable behavior. Parameter and return types make the intended inputs and outputs clear. if selects a branch, and foreach visits each item in an array.

Handling a form safely

This complete file, greet-form.php, displays a form and handles its submission. Run it with php -S localhost:8000 in the file's directory and open http://localhost:8000/greet-form.php. It validates the input and escapes the output for HTML.

<?php
$name = '';
$message = '';
$error = '';

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $name = trim($_POST['name'] ?? '');
    if ($name === '') {
        $error = 'Please enter your name.';
    } elseif (preg_match('/\A[^\r\n]{1,60}\z/u', $name) !== 1) {
        $error = 'Name must be 60 characters or fewer and fit on one line.';
    } else {
        $message = 'Welcome, ' . $name . '!';
    }
}

function e(string $value): string
{
    return htmlspecialchars($value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
?>
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>PHP form example</title>
</head>
<body>
    <form method="post">
        <label for="name">Your name</label>
        <input id="name" name="name" maxlength="60" required value="<?= e($name) ?>">
        <button type="submit">Greet me</button>
    </form>
    <p role="status"><?= e($message !== '' ? $message : $error) ?></p>
</body>
</html>
Input is untrusted. Validation checks whether submitted data meets application rules; output encoding protects the HTML context. Do not use user input to build SQL strings—use prepared statements when connecting to a database.

03String Processing and Regular Expressions

Strings are sequences of text. PHP provides functions to inspect, trim, split, search, replace, and format them. Regular expressions (regex) describe patterns in text. PHP's preg_* functions use PCRE (Perl Compatible Regular Expressions), making them useful for finding a pattern, extracting matches, or replacing matched text.

TaskPHP functionExample
Remove whitespace at the endstrim()trim(" PHP ") → "PHP"
Count charactersstrlen() / mb_strlen()Use mb_strlen() for Unicode text when the mbstring extension is enabled.
Replace literal textstr_replace()str_replace("PHP", "web", $text)

String functions and regex in one runnable example

Save as strings.php and run php strings.php.

<?php
$raw = '  Contact: learner@example.edu  ';
$clean = trim($raw);
$normalized = str_replace('Contact:', 'Email:', $clean);

echo $normalized . PHP_EOL;

$email = 'learner@example.edu';
$pattern = '/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i';
$match = preg_match($pattern, $email);

if ($match === false) {
    throw new RuntimeException('The regular expression could not be processed.');
}
echo ($match === 1 ? 'Email-like format found' : 'No email-like format found') . PHP_EOL;

$phone = '(555) 123-4567';
$digits = preg_replace('/\D+/', '', $phone);
if ($digits === null) {
    throw new RuntimeException('The replacement pattern could not be processed.');
}
echo "Digits only: $digits" . PHP_EOL;

Reading the patterns

  • /.../i uses slash delimiters; i makes matching case-insensitive.
  • ^ and $ anchor a match to the start and end of the string.
  • [A-Z0-9._%+-]+ matches one or more characters from the bracketed set.
  • \. means a literal dot; \D means any non-digit character.
Choose the right tool: Prefer simple string functions for literal replacements and searches; regex is useful when the pattern itself varies. The email pattern above checks a common email-like shape, not whether an address exists or is deliverable. For real email validation, use PHP's filter_var($email, FILTER_VALIDATE_EMAIL) and confirm ownership when needed. Regex checks do not replace server-side validation, context-appropriate output encoding, or security controls.

04Web Development Frameworks

A web framework is a reusable foundation for building applications. A PHP framework gives a project a structure and provides components for common tasks such as routing requests, validating input, rendering templates, accessing databases, handling sessions, and testing. Rather than rebuilding those pieces for each project, developers use the framework's conventions and libraries.

MVC: Model, View, Controller

Model

Represents or accesses application data and domain rules, such as a course or student record.

View

Formats the response for the user, commonly using an HTML template populated with data.

Controller

Receives a request, coordinates the relevant work, and selects the response. A route may call a controller action.

MVC is a common organizational pattern, not a requirement that every framework or application follow an identical file layout. Separating responsibilities generally makes a project easier to test and maintain.

Runnable Laravel route example

This example uses Laravel, a PHP web framework. Install Composer and a supported PHP version first. Create and start a new project with:

composer create-project laravel/laravel php-framework-demo
cd php-framework-demo
php artisan serve

Replace the contents of routes/web.php in the generated project with the complete file below. Visit the URL shown by Artisan (usually http://127.0.0.1:8000/hello). The route returns a response generated by the framework.

<?php

use Illuminate\Support\Facades\Route;

Route::get('/hello/{name}', function (string $name) {
    return view('hello', ['name' => $name]);
});

Create resources/views/hello.blade.php with this template. Blade's {{ ... }} output syntax escapes HTML by default.

<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Framework greeting</title>
</head>
<body>
    <h1>Hello, {{ $name }}!</h1>
    <p>This page is returned through a Laravel route and view.</p>
</body>
</html>

When to use a framework

  • Choose one when the application needs routing, database access, authentication, validation, and ongoing maintenance.
  • For a very small script or a learning exercise, plain PHP may be enough; understand the fundamentals before adding framework abstractions.
  • Use the framework's documented security features, keep dependencies updated, and do not assume a framework automatically makes insecure code safe.
Installation note: Composer is PHP's dependency manager. The Laravel example requires a working PHP and Composer installation and internet access to download the project dependencies; it cannot execute just by opening this study-guide HTML file.

Unit 6 at a glance

  1. PHP executes on the server and sends a response such as HTML to the client.
  2. Variables begin with $; use PHP tags, statements, arrays, conditions, loops, and functions to express application logic.
  3. Use string functions for straightforward text work and PCRE-based regex functions for pattern matching; validate input and escape output appropriately.
  4. Frameworks provide structure and reusable web components; MVC is one common way to separate responsibilities.
